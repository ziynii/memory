How it works

네 단계로 시작하는 우리 이야기

한 번 설치해 두면, 제타 채팅방에서 북마크를 눌러 문답을 열 수 있어요. GitHub에 게시된 JS를 읽는 짧은 북마클릿을 한 번 설치하면 이후 JS 업데이트도 자동으로 적용돼요.

STEP 01

북마클릿 설치

아래 설치 영역에서 코드를 복사하고 브라우저의 북마크 URL에 붙여넣어요.

STEP 02

캐릭터 방에서 실행

제타의 원하는 채팅방을 연 뒤 북마클릿을 누르면 문답 화면이 나타나요.

STEP 03

기억·API 설정

응답검토 프로필을 선택해 불러오고, 사용할 장기기억과 로어북을 체크해요.

STEP 04

함께 답하고 저장

내 답변을 등록하고 생성 버튼을 누르면 캐릭터 답변이 만들어져요. 마음에 들면 그대로 간직해요.

이제 우리 문답을 시작해 볼까요?

GitHub Pages에 공개된 실행 파일을 불러오는 짧은 북마클릿이에요. 문답 기록은 브라우저에 저장돼요.

북마클릿 설치하기 ♡

아래 버튼으로 짧은 불러오기 코드를 복사한 다음, 크롬 또는 웨일 북마크의 주소(URL) 칸에 붙여넣어 주세요. 이미 설치했다면 기존 북마크의 주소만 교체하면 됩니다.

휴대폰 브라우저는 북마클릿 실행 방식이 다를 수 있어요. PC 크롬·웨일에서 먼저 설치하는 것을 추천해요.

실행 파일: GitHub Pages의 our-little-memories.js ↗
JS 파일이 실제 배포되어야 실행됩니다. GitHub에서 교체하면 최신 버전을 불러옵니다. 제타 내부 API 호출·자동 채팅 전송은 하지 않습니다.
FAQ

사용하기 전에 궁금할 만한 것들

북마클릿이 “파일을 불러오지 못했어요”라고 표시돼요.

배포된 JS 주소가 브라우저에서 실제 JavaScript 내용으로 열리는지 확인해 주세요. 404라면 GitHub 저장소의 파일명과 Settings → Pages 배포 경로를 확인해야 해요. 파일이 열리는데도 제타에서 실패한다면 사이트의 스크립트 차단 정책 또는 브라우저 확장 기능 때문일 수 있어요.

GitHub에 저장되는 문답 기록도 있나요?

아니요. GitHub에는 실행용 JS 코드만 공개됩니다. 문답 기록은 현재 브라우저의 사이트 데이터에 저장되며, 삭제하면 사라질 수 있어요. JSON 내보내기로 따로 백업해 주세요. GitHub 저장소에는 개인 API 키를 올리지 마세요.

응답검토 기능을 실제로 실행하나요?

아니요. 응답검토의 검토·새답변·추천 기능을 호출하지 않아요. 응답검토가 브라우저에 저장한 외부 API 프로필과 로어북 선택·저장 데이터만 읽어 사용해요.

제타 내부 API나 자동 채팅 매크로를 사용하나요?

v26은 제타 내부 API를 호출하거나 제타 채팅을 자동 전송·리롤하는 기능을 넣지 않았어요. AI 답변 생성은 사용자가 연결한 외부 AI 서비스에 요청하는 별도 기능이에요.

왜 캐릭터 말투가 조금 다르게 나올 때가 있나요?

답변을 만드는 외부 AI 모델, 로어북 내용, 화면에서 실제로 읽힌 최근 대화가 모두 결과에 영향을 줘요. 설정의 ‘말투 분석 확인’에서 캐릭터 발화 예시가 추출되는지 먼저 확인해 보세요. 원래 제타 AI의 답변을 그대로 가져오는 방식은 아니에요.

API Key를 다시 입력해야 하나요?

응답검토에 저장한 API 프로필을 한 번 선택해 연결하면 다음 실행에서 같은 프로필을 다시 읽도록 설계되어 있어요. 키는 기본적으로 커플문답 백업에 넣지 않아요. 프로필 정보가 삭제되었거나 브라우저 저장소에 접근할 수 없으면 다시 연결해야 할 수 있어요.

브라우저 데이터를 삭제하면 문답도 지워지나요?

네. 문답은 브라우저 사이트 저장소에 있기 때문에 해당 사이트 데이터가 삭제되면 기록이 사라질 수 있어요. 단순 캐시 파일만 지우는 경우에는 남을 수도 있으니 구분해 주세요. 소중한 문답은 JSON으로 내보내 별도 파일로 보관하는 것을 추천해요.

JSON 백업으로 여러 캐릭터를 한꺼번에 보관할 수 있나요?

현재 v26의 JSON 내보내기는 현재 채팅방 기준이에요. 다른 캐릭터 기록까지 모두 보관하려면 각 방에서 따로 백업해 주세요. 가져오기는 현재 방 데이터를 백업 내용으로 교체할 수 있으니 확인창을 꼼꼼히 읽어 주세요.

생성 버튼을 누르지 않아도 API 비용이 발생하나요?

문답을 읽거나 내 답변을 저장하는 것만으로는 AI 생성 요청이 나가지 않아요. 캐릭터 답변 생성 또는 설정의 API 연결 테스트를 실행하면 외부 API 요청이 발생할 수 있어요. 비용은 연결한 제공자·모델의 정책에 따라 달라요.

정식으로 동작이 보장된 버전인가요?

v26은 브라우저에서 실행하는 북마클릿이에요. 제타 화면 구조나 ZETAKIT 저장 형식이 바뀌면 일부 정보가 불러와지지 않을 수 있고, 외부 API의 CORS 정책에 따라 브라우저에서 호출이 차단될 수 있어요.
